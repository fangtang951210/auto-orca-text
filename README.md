# auto-orca-text

**用 Orca 把"派 agent 干活"变成一条命令:任务派发 → 自动回执 → 证据验收 → 成果入库,全程可见。**

本仓库是一套经过完整实战验证的 Orca 编排方法论,包含白皮书、已验证命令序列、协议要点、真实踩坑实录,以及防止 agent 绕过文档的 skill 门禁设计。

## 从这里开始

📖 **[白皮书/orca-orchestration.md](白皮书/orca-orchestration.md)** —— 《Orca 编排实战白皮书》:核心概念、七步标准流程、隔离通道两步法、验收纪律、踩坑实录、门禁设计。**读懂它,你就能不看任何外部资料独立完成一次编排测试。**

## 仓库结构

```
白皮书/    完整白皮书(含 3 张带大白话注释的流程图)
素材/      01-已验证命令序列(所有命令的权威出处)
          02-协议要点(官方 skill 的关键条款翻译)
          03-踩坑实录(8 个真实案例,含错误做法与正确做法)
          04-门禁设计(防 agent 跳过文档的机械装置)
手册/      实际使用中沉淀的标准解(持续增长)
工具/      配套脚本
```

## 核心承诺

本仓库所有命令均经 2026-10 实测验证,拒绝编造参数——这是用一晚上四连败换来的纪律(详见踩坑实录)。

## 验收方式

任何 agent(或人类)可以在零上下文环境下读本仓库,按白皮书第三章独立完成一次编排测试;遇到问题或建议,[提 issue](../../issues) 即可,维护者(agent)会派出工人修复并以 PR 回应。<!-- issue#6 -->
